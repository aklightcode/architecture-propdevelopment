Задание 3. Внешние интеграции

### Процедуры аутентификации и авторизации

1. Доступ к функционалу «Умный дом» в мобильном приложении предоставляется через единую систему авторизации PropDevelopment.
2. Для серверного взаимодействия применяются протоколы OAuth 2.0 или JWT с обязательной цифровой подписью.
3. Участники взаимодействия обмениваются открытыми ключами для верификации подписей запросов.
4. При обращении к внешнему сервису система PropDevelopment действует как доверенный посредник, передавая токен пользователя. Данный токен содержит сведения о пользователе и запрашиваемом действии. Внешняя платформа проверяет валидность подписи токена и предоставляет доступ, если пользователь имеет соответствующие права.
5. В мобильном приложении реализован механизм обновляемых токенов (refresh tokens).
6. Повторная аутентификация пользователя требуется после 30 минут отсутствия активных действий.

### Критерии обеспечения безопасности

1. Все информационные потоки между внешними платформами партнёров и системой PropDevelopment должны использовать защищённые соединения TLS.
2. Биометрическая информация (изображения лиц) и номера транспортных средств подлежат дополнительному шифрованию на уровне приложения (с применением функций шифрования PostgreSQL).
3. Доступ к API сторонних сервисов должен контролироваться через белый список IP-адресов, разрешающий подключения только с серверов PropDevelopment.
4. Архитектура системы должна быть разработана в соответствии с положениями Федерального закона №152 «О персональных данных», в особенности в части обработки биометрической информации.
5. Партнёры обязаны предоставлять все необходимые документы, подтверждающие соответствие их инфраструктуры требованиям информационной безопасности.

### Архитектурные принципы интеграции

Пользователь получает доступ к функционалу через Витрину сервисов для собственников, откуда может перейти в раздел «Умный дом». В данном разделе ему доступно управление домофоном и шлагбаумом. Непосредственная реализация функций «умного дома» осуществляется на стороне партнёра, в то время как PropDevelopment обеспечивает процессы аутентификации и авторизации.
В базе данных модуля «Умный дом» сохраняется актуальное состояние устройств, перечень подключённых услуг, доступных для управления, а также журнал неудачных попыток выполнения команд.

Персональные данные собственников хранятся исключительно в инфраструктуре PropDevelopment. Партнёрам передаются только обезличенные идентификаторы (id) или токены.

Видеопоток с домофона сохраняется в базе данных PropDevelopment «Умный дом». В процессе видеозвонка данные шифруются при передаче сервису партнёра и не сохраняются на его стороне после завершения сеанса.

PropDevelopment выполняет роль единой точки входа для пользователей мобильного приложения. Взаимодействие с внешними сервисами партнёров организовано через RESTful API.

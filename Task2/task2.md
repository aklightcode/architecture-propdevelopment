Задание 2. Разработка и заполнение проверочного листа для бизнес-систем    
| №  | Вопрос                                                                                                           | Да/Нет | Комментарий                                                                                                                                                                                                 |    
|----|------------------------------------------------------------------------------------------------------------------|--------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|    
| **Управление доступом** |    
| 1  | Используется ли многофакторная аутентификация (MFA)                                                              | Нет    | Многофакторная аутентификация необходима, так как в системе есть чувствительные данные: личная информация, документы о сделках, платёжные поручения                                                                                                  |    
| 2  | Используются ли средства централизованного контроля доступа?                                                     | Да     | Есть единое хранилище учётных записей                                                                                                                                                                           |    
| 3  | Используются ли системы аутентификации пользователей для доступа к системам?                                     | Да     | Наличие единой точки входа позволяет управлять процессом аутентификации                                                                                                                                          |    
| 4  | Ведётся ли журналирование всех операций доступа к системам и данным?                                             | Нет    | Так система предоставляет доступ к разным данным разным группам пользователей, то желательно иметь журнал доступа к данным                                                                                 |    
| 5  | Созданы ли замкнутые контуры для подсистем, работающих с чувствительными данными?                               | Нет    |  Разграничение доступа к данным по ролям и привилегиям необходимо для контроля потока данных                                                                                                         |    
| 6  | Реализован ли принцип минимальных привилегий при назначении ролей и прав доступа?                               | Нет    | В системе отсутствует механизм ролей                                                                          |    
| **Безопасность данных** |    
| 1  | Разработана ли политика классификации данных, и актуализируется ли она в соответствии с действующим законодательством? | Нет    | Классификация данных отсутствует. Нет шифрования и обезличивания                                                                                                                          |    
| 2  | Используется ли шифрование на уровне базы данных, файловой системы и при передаче данных по сети?               | Нет    |  Шифрование необходимо для защиты секретных данных                                                                                                                                                         |    
| 3  | Проводится ли регулярное резервное копирование данных?                                                          | Нет    |  Критически важно иметь копию данных в защищённом хранилище                                                                                                                                         |    
| 4  | Применяются ли средства или процессы анонимизации данных?                                                       | Нет    | Не применяются, но должны, так как обезличенное хранение данных необходимо для соответствия 152-ФЗ                                                                                                                                             |    
| 5  | Настроены ли VPN и шифрование для безопасного удалённого доступа к корпоративным ресурсам?                     | Нет    |  VPN и шифрование для безопасного удалённого доступа к корпоративным ресурсам необходимы так как  Бизнес-аналитик и BI должны подключаться через VPN                                                                                                                                                  |    
| **Защита инфраструктуры** |    
| 1  | Используется ли межсетевой экран для ограничения входящего и исходящего трафика?                               | Да     |  Внутренняя система должна быть изолирована от внешней                                                                                                                                                |    
| 2  | Настроен ли мониторинг сетевого траффика на предмет аномалий и возможных атак, например, DDoS?                 | Нет    |  Необходимо отслеживать сетевой траффик и возможные атаки в контексте обеспечения информационной безопасности                                                                                                                                                                                       |    
| 3  | Осуществляется ли фильтрация трафика между сетевыми сегментами?                                                | Нет    |  Необходимо иметь информацию, о том чем обмениваются компоненты внутри системы                                                                       |    
| **Управление инцидентами** |    
| 1  | Используется ли система мониторинга безопасности (SIEM) для корреляции событий и анализа аномалий в режиме реального времени? | Нет    | Необходимо использовать для своевременного реагирования на угрозы                                                                                                                                                               |
